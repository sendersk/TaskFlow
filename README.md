
# TaskFlow

A task and workflow management system built with Python and FastAPI.

TaskFlow provides a REST API for managing projects, tasks, priorities,
deadlines, task dependencies, and activity history.

## Features

- Project and task management
- Task priorities and status tracking
- Task dependencies and validation
- Deadline management
- Activity history
- REST API with automatic OpenAPI documentation

## Technology Stack

- Python 3.13+
- FastAPI
- Pydantic
- SQLAlchemy
- SQLite
- Alembic
- pytest
- Docker

## Project Status

Under active development.
